# examples

Self-contained, copy-paste capabilities an enclave agent can use. Each is a folder with a README and
runnable code — drop it next to your agent.

| example | what it does |
|---|---|
| [vision-captcha](vision-captcha/) | Read image/text CAPTCHAs with your own vision model — vendor-free, zero deps. |

Building a purpose-built agent instead? See [`../templates/`](../templates/) and
[`../docs/QUICKSTART.md`](../docs/QUICKSTART.md).
